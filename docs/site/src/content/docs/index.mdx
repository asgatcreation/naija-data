## Install in a minute

<Tabs syncKey="lang">
  <TabItem label="JavaScript" icon="seti:javascript">
  ```bash
  npm install naija-data
  ```
  ```ts
  import { states, lgas, isValidNuban, parsePhone } from "naija-data";

  lgas("Lagos").map((l) => l.name);        // ["Agege", "Ajeromi/Ifelodun", ...]
  isValidNuban("0000014579", "011");       // true
  parsePhone("0803 123 4567")?.e164;       // "+2348031234567"
  ```
  </TabItem>
  <TabItem label="Python" icon="seti:python">
  ```bash
  pip install naija-data
  ```
  ```python
  import naija_data as ng

  [l.name for l in ng.lgas("Lagos")]        # ['Agege', 'Ajeromi/Ifelodun', ...]
  ng.is_valid_nuban("0000014579", "011")    # True
  ng.parse_phone("0803 123 4567").e164      # '+2348031234567'
  ```
  </TabItem>
  <TabItem label="Go" icon="seti:go">
  ```bash
  go get github.com/asgatcreation/naija-data/go
  ```
  ```go
  lgas, _ := naija.LGAs("Lagos")
  ok, _ := naija.IsValidNUBAN("0000014579", "011") // true
  naija.ParsePhone("0803 123 4567").E164           // "+2348031234567"
  ```
  </TabItem>
  <TabItem label="REST API" icon="seti:json">
  ```bash
  curl https://naija-data-api.asgatcreation.workers.dev/v1/states/lagos/lgas
  ```
  Free, no key, CORS open: call it straight from a web page. [All endpoints](/reference/api/).
  </TabItem>
  <TabItem label="No code" icon="document">
  Download the CSV files for Excel, Google Sheets, a database, PHP, Java, Flutter or any other tool.
  [Use the data files](/guides/raw-data/).
  </TabItem>
</Tabs>

## Why naija-data

<CardGrid>
  <Card title="Every record has a source" icon="document">
    INEC, the Constitution, the CBN, the NCC and the Official Gazette, each recorded with URL, date and licence.
    Values from a single source are flagged. [See the sources](/data/sources/).
  </Card>
  <Card title="Errors in official lists, caught" icon="warning">
    Cross-checking found a duplicated INEC ward, typos in official names, duplicated constituency codes and banks
    sharing a code. Each is documented. [Coverage and gaps](/data/coverage/).
  </Card>
  <Card title="Same answers everywhere" icon="seti:json">
    Python, JavaScript, Go and the API come from one dataset, and over 13,000 shared tests check that they
    agree, down to the search scores.
  </Card>
  <Card title="Free and open" icon="heart">
    Code under MIT, data under CC BY 4.0: use it in commercial apps, just give credit. No API key, no sign-up.
  </Card>
</CardGrid>
