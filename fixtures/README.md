# Parity fixtures

`parity.json` holds shared test cases. The Python, JavaScript and Go packages each run every
case and must produce exactly the `expect` value. That is how we guarantee the three packages
behave identically, including fuzzy-search scores.

The file is generated by `python scripts/build/make_fixtures.py` from the Python package (the
reference implementation), whose correctness is covered by hand-written tests. Regenerate it
whenever the data or the behaviour changes, and review the diff.

## Case format

```json
{"fn": "get_state", "args": ["lagos"], "expect": "LA"}
```

`null` in `args` means "argument not given". A function that raises (Python `ValueError`, JS
`Error`, Go non-nil `error`) is expected as `{"error": true}`.

## Shared algorithms

- **Normalised key** (`norm`): Unicode NFKD, drop non-ASCII, lower case, `&` → `and`, split on
  anything that is not `a-z0-9`, drop trailing words `state`/`lga` while more than one word remains,
  join without spaces. `"Akwa-Ibom State"` → `akwaibom`.
- **Score** (`score(q, t)`, integers only): `1000` if equal; if `t` starts with `q` and `len(q) ≥ 2`:
  `900 + floor(99·len(q) / len(t))`; otherwise `floor((m − d)·800 / m)` where `m = max(len)` and `d` is
  the optimal string alignment distance.
- **Search** keeps candidates scoring at least 600 and sorts by score (high first), then kind
  (state, lga, ward), then name, then code, comparing strings by code point.
- **NUBAN** (CBN Revised Standards): institution code = `000` + 3-digit code or `9` + 5-digit code;
  weights `3,7,3,3,7,3,3,7,3,3,7,3,3,7,3`; check digit = `(10 − sum mod 10) mod 10`.
